Connect. Observe. Interact. Capture. Continue.

Cockroach Browser gives a host AI agent a direct, structured route from semantic page state to a real Chromium, Firefox, or WebKit action and a reviewable result.

01

Connect

Use MCP, BrowserRuntime, BrowserClient, the authenticated HTTP API, or the CLI.

02

Observe

Capture visible text, page state, roles, accessible names, frames, and snapshot-scoped references.

03

Interact

Navigate, use forms, tabs, keyboard, pointer, drag, files, dialogs, downloads, and exact element targets.

04

Capture

Keep screenshots, PDFs, paired captures, traces, HAR, video, console, network, audits, and visual diffs.

05

Continue

Return structured outcomes and receipt hashes to the host agent, then refresh page state before the next step.

Challenges are a handoff, not a bypass target.

The runtime detects login, consent, CAPTCHA, and access challenges, records the state, pauses automation, and waits for a human or authorized resolver. It does not defeat site controls or claim access after a site denies it.
