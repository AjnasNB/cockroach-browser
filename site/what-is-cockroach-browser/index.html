Product definition

What is Cockroach Browser?

A local-first browser execution and evidence runtime for AI agents.

Cockroach Browser gives a host agent an explicitly authorized Chromium session. It combines semantic page references, real interactions, finite policy budgets, evidence artifacts, and hash-linked receipts in one TypeScript package.

Install and get started Inspect every capability

The product boundary.

The runtime controls one admitted browser session; the operator and host retain the surrounding authority.

Session

Explicit browser authority

Origins, actions, effects, profiles, credentials, time, requests, and byte ceilings are declared before use.

Observe

Semantic page references

Bounded snapshots expose stable, snapshot-scoped refs so a host can target page elements without relying only on coordinates.

Act

Real browser interaction

Navigate, click, type, select, scroll, upload admitted files, handle state, and capture results inside the session policy.

Prove

Evidence and receipts

Link actions to URLs, input and output digests, screenshots, PDFs, traces, network observations, and a hash-chained receipt history.

Connect

Daemon, SDK, and MCP

Embed the TypeScript runtime, call an authenticated local daemon, or expose bounded observation and proposal tools through MCP.

Govern

Optional external authority

Route selected consequential actions through a separately configured approval boundary while preserving the browser session and evidence record.

What it does not claim.

Cockroach Browser is not an autonomous planner, a browser engine, an ambient profile scanner, or an access-control bypass system. Login, consent, CAPTCHA, and denied-access states stop for human or separately authorized handling.
