Capability matrix

130 named surfaces. No hidden universal-access claim.

119 runtime surfaces are available, 11 require an external integration authority, and 0 remain planned.

Read the source status

This matrix is generated from current main for the next release. Available means implemented in this source tree; it does not by itself prove publication in 0.5.0-rc.1. Adapter means the integration contract is present but another package or host authority is required. Planned means the direction is documented and is not implemented here.
